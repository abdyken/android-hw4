# Tip Time — extra tasks

## Codelab 2 optional task: add leading icons to text fields

Requirements:
- Add a `leadingIcon` parameter annotated with `@DrawableRes` to `EditNumberField()`
- Show the icon inside the `TextField` with the `leadingIcon` slot using `Icon` and `painterResource`
- Use `R.drawable.money` for the Bill Amount field
- Use `R.drawable.percent` for the Tip Percentage field
- Icons are decorative so `contentDescription` is `null`
